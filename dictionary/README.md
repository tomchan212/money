# UI 文字字典

此資料夾存放 Web App 所有使用者可見文字（繁體中文／粵語口語）的參考字典。

## 檔案

| 檔案 | 用途 |
|------|------|
| `ui-strings.zh-Hant.json` | 完整 UI 文字目錄，按畫面區塊分類 |

## 來源

- **靜態文字**：`index.html` 內的標籤、按鈕、placeholder、aria-label
- **動態文字**：`app.js` 內的常數、toast、空狀態、結算說明等
- **不含**：`syncManager.js`、`offlineQueue.js`（無 UI 文字）

## 對載入速度有幫助嗎？

**一般情況下：不會明顯加快載入。**

| 做法 | 對載入的影響 |
|------|----------------|
| 只放字典檔在資料夾（目前做法） | 無影響 — 瀏覽器不會下載 |
| 額外 `<script>` 載入字典 | 略為**變慢**（多一個 HTTP 請求 + JSON 解析） |
| 把字典嵌入 `app.js` 並重構全部文案 | 體積相近，速度差不多；好處是**統一管理** |
| 多語言 + 按需載入 locale | 可**加快**首屏（只載入一種語言） |

### 字典的真正用途

1. **集中查閱**：改文案時先查字典，避免同一意思多種寫法
2. **維護一致**：例如「畀／俾」等用字統一
3. **日後 i18n**：若要加英文版，可在此擴充 `ui-strings.en.json`
4. **給設計／測試**：不用開 App 也能 review 全部文案

## 佔位符

動態字串使用 `{name}` 佔位符，例如：

```json
"repayExceedsDebt": "還錢金額唔可以超過欠款 {amount}"
```

執行時由 `app.js` 代入實際值。

## 更新方式

修改 `index.html` 或 `app.js` 文案後，請同步更新 `ui-strings.zh-Hant.json`。
